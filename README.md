# ⛵ Система управления заказами на яхты — 1С:Предприятие 8.3

**Учебный проект разработчика 1С | Портфолио Junior 1С-разработчика**

Информационная система для автоматизации процессов компании, занимающейся производством и продажей яхт.

Проект разработан с нуля в рамках профессиональной переподготовки по программе «1С-разработчик» в Национальном исследовательском Томском государственном университете (2025).

## 🎯 Цель проекта

Создать конфигурацию 1С для ведения каталога продукции, оформления клиентских заказов, учёта цен и подготовки отчётности.

Проект демонстрирует практические навыки разработки информационной системы на платформе 1С:Предприятие 8.3.

## 🛠 Технологии и инструменты

- Платформа 1С:Предприятие 8.3
- Конфигуратор 1С
- Встроенный язык программирования 1С
- Справочники и документы
- Регистры сведений
- Управляемые формы
- Отчёты
- GitHub для хранения проекта и документации

## 📋 Функциональные возможности

**1. Каталог продукции**

- Учёт моделей яхт
- Хранение информации о материалах и цветах
- Учёт аксессуаров и комплектующих

**2. Управление заказами**

- Оформление заказов клиентов
- Учёт предварительной оплаты
- Ведение графика платежей
- Работа с договорами и приложениями

**3. Учёт цен**

- Документ установки цен
- Хранение истории изменения цен в регистре

**4. Работа с контрагентами**

- Ведение данных клиентов и поставщиков
- Учёт сотрудников
- Настройка пользовательского интерфейса

**5. Отчётность**

- Анализ заказов
- Формирование списка премиальных клиентов

## 🚀 Как запустить проект

1. Установить платформу 1С:Предприятие 8.3.
2. Создать новую информационную базу.
3. Открыть её в режиме «Конфигуратор».
4. Выбрать «Администрирование → Загрузить информационную базу».
5. Указать файл `.dt` из каталога `Database/`.
6. После восстановления запустить базу в режиме 1С:Предприятие.

**Внимание:** восстановление файла `.dt` заменяет содержимое выбранной информационной базы. Используйте отдельную пустую базу.
